# Security Policy

## Reporting a Vulnerability

Please do not disclose security vulnerabilities through public GitHub issues.

If you discover a vulnerability, contact the repository maintainer privately through an available private contact channel on the maintainer's GitHub profile.

Please include enough information to reproduce and evaluate the issue.

Do not include real student data, credentials, access tokens, database dumps, or other sensitive information in vulnerability reports or public issues.

## Sensitive Data

SPMB MARSA processes student registration information and may contain personally identifiable information when deployed.

Production databases, `.env` files, API credentials, access tokens, backups, and uploaded documents must never be committed to this repository.
